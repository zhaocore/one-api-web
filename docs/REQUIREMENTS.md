# One API Web 需求文档

> 本文档是 One API 管理控制台前端（`one-api-web`）的**规范需求文档**。
> 它是活文档：任何行为变更或澄清都必须同步更新本文档；需求与代码冲突时，以代码与通过测试为准，并在同一改动中修正本文档。
> 层级约定：`##` 为一级需求，`###` 为二级需求，`####` 为三级细节。不超过三级。

## 1. 产品概述

### 1.1 背景与目标

- 基于 **Vite + React + TypeScript + Tailwind CSS** 构建的 One API 管理控制台前端。
- 提供模型渠道、访问令牌、用量日志、用户与系统配置的统一管理界面。
- 与后端通过 `/api/*` REST 接口通信，前端为纯 SPA，不包含服务端代码。

### 1.2 用户角色

- 普通用户（`role = 1`）：登录、查看仪表盘与本人令牌、查询本人日志、个人中心、充值。
- 管理员（`role = 10`）：在普通用户基础上，可管理渠道、兑换码、用户、系统设置，可查看全部日志。
- 超级管理员（`role = 100`）：具备管理员全部能力，是权限模型的最高级别。
- 权限判断依据 `src/utils/permission.ts`：`isAdmin` 为 `role >= 10`，`isRoot` 为 `role >= 100`。

### 1.3 技术约束

- Node.js ≥ 20（以仓库 `.nvmrc` 为准），包管理使用 pnpm。
- 状态管理使用 Jotai，`atomWithStorage` 做 localStorage 持久化。
- 路由使用 React Router 6 `createBrowserRouter`。
- 表单使用 React Hook Form + Yup / Zod 校验。
- 图表使用 ApexCharts，国际化使用 i18next。
- 开发端口 `127.0.0.1:3090`，`/api` 代理到 `VITE_API_PROXY_TARGET`（默认 `http://127.0.0.1:3067`）。

## 2. 认证与授权

### 2.1 登录

- 支持用户名 + 密码登录。
- 登录成功后保存当前用户到 localStorage 键 `user`，`accountAtom` 与 API 层 401 登出逻辑必须保持该键一致。
- 登录页为根路由 `index` 与 `/login`，未登录访问 `/panel` 由 `AuthGuard` 拦截。

### 2.2 注册

- 支持 `/register` 注册页面。
- 支持忘记密码（`/reset`）与重置密码（`/user/reset`）。

### 2.3 OAuth 登录

- GitHub OAuth：`/oauth/github`，跳转 GitHub 授权页。
- 飞书 OAuth：`/oauth/lark`，跳转飞书授权页。
- OIDC OAuth：`/oauth/oidc`，跳转 OIDC 授权端点。
- OAuth 前必须先获取 `/api/oauth/state`，失败则中止跳转。
- OAuth 配置（client id、授权端点等）来自后端 `SiteInfo`，前端不得硬编码。

### 2.4 人机校验与登出

- Turnstile 人机校验：站点开启 `turnstile_check` 时，登录/注册需通过 Turnstile。
- 任何接口返回 401 时自动登出并跳转登录页，不得绕过。

### 2.5 权限边界

- 路由守卫：`AuthGuard` 保护 `/panel` 下所有页面；`AdminGuard` 保护渠道、兑换码、用户、系统设置。
- 列表行级控制：使用 `hasAdminRole(role)` 判断行内操作是否可见。
- 普通用户仅能管理本人令牌、查询本人日志，管理员可查看全部。

## 3. 仪表盘

### 3.1 总览统计

- 展示额度、请求数与 Token 用量统计（折线图与柱状图可视化）。
- 数据来源 `/api/user/dashboard`，聚合项包含日期、模型、请求数、额度、Prompt/Completion Tokens（`LogStatistic`）。
- 支持按模型维度筛选。

### 3.2 最近日志

- 展示最近用量日志，管理员可查看全部用户，普通用户仅本人。

## 4. 渠道管理

### 4.1 渠道列表

- 渠道增删改查、启用/禁用状态切换与优先级调整。
- 展示响应时间、测试时间、余额、已用额度、模型列表等信息。

### 4.2 渠道表单

- 按渠道类型动态渲染表单字段（不同类型字段不同）。
- 支持模型映射（`model_mapping`）、分组（`group`）、权重（`weight`）等配置。

### 4.3 测速

- 支持对渠道执行测速，展示测试时间与响应时间结果。

## 5. 令牌管理

### 5.1 令牌列表

- 令牌增删改、启用/禁用切换。
- 展示剩余额度、已用额度、过期时间、访问时间等。

### 5.2 令牌编辑

- 支持编辑额度、设置过期时间、`unlimited_quota` 无限额度开关。

### 5.3 密钥复制

- 支持一键复制 `sk-` 前缀的密钥，复制内容不得截断或改写。

## 6. 日志查询

### 6.1 查询范围

- 管理员可查询全部用户日志，普通用户仅本人日志。

### 6.2 筛选与分页

- 支持多条件筛选（时间、模型、状态等）与分页。
- 展示消耗统计汇总。

## 7. 用户管理

### 7.1 用户列表

- 用户增删改、额度调整、启用/禁用切换。

### 7.2 角色管理

- 管理员提升与降级（普通用户 / 管理员 / 超级管理员）。
- 角色变更必须遵守 1 / 10 / 100 编号约定。

## 8. 兑换码

### 8.1 兑换码生成

- 支持单个与批量生成兑换码，配置额度与数量。

### 8.2 状态追踪

- 状态编号约定：`1` 未使用、`2` 已禁用、`3` 已使用（`REDEMPTION_STATUS`）。
- 支持状态追踪、删除与禁用。

## 9. 充值与邀请

### 9.1 充值

- 支持兑换码充值（`/topup`）。

### 9.2 邀请

- 支持邀请码推广，邀请链接带入邀请码。

## 10. 系统设置

### 10.1 设置分类

- 运营设置、系统设置、其他设置三类，分 Tab 管理。
- 设置项来自后端 `SiteInfo` 与配置接口，前端仅做展示与提交。

## 11. 个人中心

### 11.1 资料与密码

- 个人资料编辑、密码修改。

### 11.2 开发者令牌

- 展示开发者令牌与访问凭证。

## 12. 主题与响应式

### 12.1 主题

- 亮色 / 暗色 / 跟随系统三种模式，持久化到 localStorage（键 `color-theme`）。

### 12.2 响应式

- 桌面与移动端自适应布局，侧边栏可折叠（键 `sidebarExpanded` 持久化）。

## 13. 国际化与无障碍

### 13.1 国际化

- 支持 `en`、`zh-Hans`、`zh-Hant` 语言，默认跟随浏览器语言。
- 语言偏好持久化到 localStorage（键 `lang`）。
- 已知缺口：`src/locales/i18n.ts` 当前为 stub，`resources` 为空，`locales/en|zh-Hans|zh-Hant` 目录为空，国际化尚未真正生效。

### 13.2 无障碍

- 组件与页面需满足基本无障碍要求（`src/a11y/`、`src/common/a11y.ts`、`LiveAnnouncer`）。
- UI 自动化与测试优先使用稳定 ID / test ID / 无障碍 ID，而非可见文本。
